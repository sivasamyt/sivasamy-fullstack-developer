# Light Theme Project

This project is a simple application that implements a light theme. It serves as a demonstration of how to structure a TypeScript project with a focus on theming.

## Project Structure

```
light-theme-project
├── src
│   ├── index.ts          # Entry point of the application
│   └── theme
│       └── light.ts      # Contains the light theme styles
├── package.json          # NPM configuration file
├── tsconfig.json         # TypeScript configuration file
└── README.md             # Project documentation
```

## Installation

To get started with this project, clone the repository and install the dependencies:

```bash
git clone <repository-url>
cd light-theme-project
npm install
```

## Usage

To run the application, use the following command:

```bash
npm start
```
